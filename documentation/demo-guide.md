# Parcours de démonstration ARCHIVIA (10–15 minutes)

## Préparation

1. Ouvrir le site local ou son URL Vercel.
2. Choisir **Mode démonstration locale** et le profil fictif à présenter.
3. Vérifier le bandeau **MODE DÉMONSTRATION LOCAL**. Toutes les données d’exemple et modifications restent dans le navigateur.
4. Au besoin, cliquer sur **Réinitialiser les données** pour rétablir les données de l’organisation active.
5. Aucun compte externe, service cloud ou identifiant n’est requis.

## Déroulé suggéré

1. **Tableau de bord (2 min)** — présenter les indicateurs calculés à partir des données locales.
2. **Dossiers (2 min)** — consulter un dossier, en créer un, modifier ses métadonnées ou le clôturer.
3. **Documents (2 min)** — rechercher un document fictif, consulter ses métadonnées puis importer un PDF ou une image de démonstration. Le fichier est temporaire dans l’onglet.
4. **Validations (1 min)** — approuver un document d’exemple ou demander une correction; le statut change dans les données locales.
5. **Archives physiques (1 min)** — parcourir l’inventaire fictif et les emplacements.
6. **Prêts & retours (1 min)** — créer une demande, l’approuver et enregistrer un retour.
7. **Recherche (1 min)** — rechercher par titre, référence, catégorie ou service.
8. **Audit, profils, organisations et rapports (2 min)** — montrer l’activité locale, les profils fictifs, les espaces d’exemple et les indicateurs exportables en CSV.

## Réinitialisation

- Utiliser **Réinitialiser les données** dans le bandeau; cela restaure uniquement l’organisation active.
- Pour repartir entièrement de zéro, effacer les données du site dans les paramètres du navigateur ou supprimer les clés `archivia-demo-*` du `localStorage`.
- Pas de commande serveur ni de base à réinitialiser.

## Limites à annoncer

- Les profils de présentation ne sont pas des comptes; leur sélection ne fournit ni authentification ni permissions sécurisées.
- Les données sont locales au navigateur et ne sont ni partagées entre visiteurs, ni sauvegardées côté serveur.
- Les documents d’exemple sont des métadonnées fictives sans fichier binaire; les imports sont temporaires à l’onglet.
- Les activités affichées sont un journal de démonstration local, pas une piste d’audit sécurisée.
- Les emplacements, politiques de conservation et statistiques sont fictifs. Aucun OCR, IA, certificat de destruction ou service cloud n’est inclus.
